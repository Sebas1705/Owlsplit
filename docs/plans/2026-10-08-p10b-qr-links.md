# P10b · Invitaciones: QR, página de Hosting y App Links — Implementation Plan

> **For agentic workers:** Use `mobiai-mobile-executing-plans-with-subagents` (recommended) or `mobiai-mobile-executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Completar las invitaciones ([3.8](../designs/2026-10-07-owlsplit-core-design.md#38-invitaciones)): el enlace de invitación abre la app (App Links) o, si no está instalada, una página con el código; la pantalla Invitar muestra un QR con el enlace y Unirse puede escanearlo.

**Architecture:**
- `core:ui`: `QrCode` (qrose 1.1.2, siempre oscuro sobre blanco) y el puerto `QrScanner`.
- `composeApp`: `AndroidQrScanner` (Google code scanner de Play services: su propia cámara, sin permiso de cámara para la app); filtro `https://<host de invitación>/j/` con `autoVerify` (host por entorno con `manifestPlaceholders`), `MainActivity` `singleTask` que entrega el enlace a `IncomingInvites`; `AppRoot` abre Unirse con el código cuando ya se ven las pestañas (tras el onboarding si es la primera vez).
- `firebase/hosting`: `join.html` para `/j/**` (código, "Abrir en Owlsplit" con `intent://` en Android, copiar código, pasos si no hay app), página de inicio y `.well-known/assetlinks.json` (paquete `.dev` con la huella SHA‑256 de depuración).

**Platform:** KMP (Android verificado en emulador contra `owlsplit-dev`; iOS compila en CI)

**Depende de:** P10a.

---

## Decisiones

1. **QR**: qrose 1.1.2, la última que no exige Compose 1.12 ni compileSdk 37 (Dependabot la retiene). Contiene el enlace, no solo el código: un móvil sin la app abre la página de Hosting con la cámara del sistema.
2. **Escáner**: Google code scanner (`play-services-code-scanner`); el módulo se descarga la primera vez que se resuelve el escáner. Un QR que no es de Owlsplit da "código no válido". En iOS no hay opción de escanear hasta P11 (AVFoundation).
3. **App Links**: verificados con `assetlinks.json`; el enlace abre Unirse con el código ya buscado. Si la app no tiene perfil, el enlace espera a que termine el onboarding. Universal Links (iOS) en P11 con el proyecto Xcode (`apple-app-site-association` necesita el Team ID).
4. **Página `/j/<código>`**: estática, sin SDK de Firebase; valida el alfabeto del código; en Android ofrece `intent://…;package=<paquete del entorno>` para abrir la app aunque el navegador no entregue el enlace. Sin enlaces a tiendas hasta que la app esté publicada.
5. **Producción**: el sitio `owlsplit.web.app` y la huella de la clave de publicación llegan con P11 (proyecto prd y firma).
