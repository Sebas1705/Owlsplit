# P10a · Invites: code, link, joining and claiming a member — Implementation Plan

> **For agentic workers:** Use `mobiai-mobile-executing-plans-with-subagents` (recommended) or `mobiai-mobile-executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Invite people to a group and join one ([3.8](../designs/2026-10-07-owlsplit-core-design.md#38-invitations)): an 8-character code and a link to share, regenerating the code, joining by typing the code (or pasting the link), previewing the group and choosing who I am (claim a member without an account or add myself as new). QR, the Hosting page and App Links / Universal Links are left for P10b.

**Architecture:**
- `data`: `InviteService` (port in `data:repository`) with `FirestoreInviteService` (`invites/{code}` and the join write with `arrayUnion`/`increment`/`serverTimestamp`, which the rules validate against `lastJoinCode`); `GroupRepository.regenerateInviteCode`, `MemberRepository.claim` and `addMe` (recorded as `JOINED`). `InvitePreview` and `PreviewResult` in `data:models`.
- `domain` (`invite`): `InviteCodes` (normalize, validate, display as "ABCD EFGH"), `ShareInvite`, `RegenerateInvite`, `PreviewInvite`, `JoinGroup` (waits for the group to arrive through sync) and `ClaimMember`.
- `feature:invite`: Invite and Join screens with their ViewModels. `TextSharer` in `core:ui` (share sheet on Android; on iOS it copies to the clipboard until P11).
- `composeApp`: `inviteModule`, `AppConfig.INVITE_BASE_URL` per environment, routes `InviteDest` and `JoinDest(code?)`.

**Platform:** KMP (Android verified on emulator against `owlsplit-dev`; iOS compiles in CI)

**Depends on:** P9.

## Decisions

1. **Publish on share**: opening Invite flushes the outbox (the group with its current code must be on the server, which is what the rules require) and writes `invites/{code}` with the name, icon and member count. Offline, you can't invite.
2. **Regenerate** changes the code (outbox, no history entry), uploads it and deletes the previous `invites/{code}`: old links stop working.
3. **Join**: the code is accepted with spaces, hyphens, in lowercase or as a full link (`…/j/CODIGO`). The preview reads from the server (`Source.SERVER`); a nonexistent or forbidden code is "no válido o caducado" ("invalid or expired").
4. **After joining**, it waits (up to 30 s) for the group to arrive through sync and shows the active members without an account so you can claim one, or "Soy nuevo: añadirme como <nombre del perfil>" ("I'm new: add me as <profile name>"). If I already had a member (rejoining), the group opens directly.
5. **Entry points**: "Invitar" ("Invite") in the group menu; "Unirme" ("Join") in the Home quick actions, "Tengo un código de invitación" ("I have an invite code") on the empty Home and "Unirme con un código" ("Join with a code") in onboarding. When finished, the group opens and Join is removed from the back stack.
